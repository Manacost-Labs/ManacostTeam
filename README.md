# ManacostTeam

Единый репозиторий рабочих направлений Manacost Labs. Каждый модуль остаётся самодостаточным: его исходный код, зависимости, документация и правила работы находятся внутри соответствующей папки.

| Модуль | Назначение |
|---|---|
| [`editor/`](editor/) | Навыки и инструменты редакционного контура |
| [`research/`](research/) | Исследовательские инструменты и эксперименты |
| [`svg/`](svg/) | Генератор SVG-графиков Hearthstone |
| [`job/`](job/) | Чат-навыки для оценки вакансий и отбора авторов |

## Работа с репозиторием

Начинайте с README и `AGENTS.md` нужного модуля. Не переносите зависимости и настройки между модулями без отдельной задачи: монорепозиторий объединяет историю и навигацию, но не заставляет независимые инструменты иметь общий рантайм.

## История

История `editor/`, `research/` и `svg/` сохранена через subtree-импорт. `job/` добавлен из локального набора skill-пакетов, поскольку отдельного Git-репозитория у него не было.
