# Перевод WoW и Hearthstone

Перевод делает Codex в чате; локальный контейнер TranslateTeam только готовит материал и QA-отчёт. Не вызывай локальную LLM и не подменяй перевод облачным API без отдельного запроса пользователя.

1. Зафиксируй игру, патч/версию, класс, специализацию, тип материала и режим стиля. Если URL или текст уже передан через TranslateTeam, используй его контекст и защищённые маркеры.
2. Для Hearthstone сверяй имена с базой, собранной одной числовой сборкой HearthstoneJSON; для WoW — с парной enUS/ruRU-выгрузкой одного клиента и билда. Не утверждай имя на основании созвучия, машинного перевода или фанатской памяти.
3. Сохрани Markdown, ссылки, таблицы, код, числа, проценты, IDs, порядок приоритетов и маркеры [[[TERM_n]]]. Восстанови каждый маркер утверждённым русским термином.
4. В первом проходе переведи весь текст в выбранном стиле, не добавляя причин, механик, статистики или рекомендаций, которых нет в оригинале.
5. Во втором проходе выполни редакторский QA: сопоставь числа, ссылки и названия; проверь, что ни один маркер не утёк в результат и не потеряны предложения. Если есть QA-отчёт TranslateTeam, исправь перечисленные несоответствия.
6. Термин без подтверждённой пары оставь в отдельном блоке «На проверку» с контекстом, а не добавляй молча в утверждённую базу. Однословные имена из массовой выгрузки не защищаются автоматически; добавляй их только с пометкой manual=true и источником.
7. Если имеется memory match из утверждённой translation memory, используй его лишь при совпадении смысла и контекста. Не переносите старую формулировку на иной патч или специализацию автоматически.

Для страницы, недоступной из-за CAPTCHA, логина или динамической загрузки, попроси пользователя вставить текст. Не обходи ограничения источника.
