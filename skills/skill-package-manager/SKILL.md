# Управление skill-пакетами

Исходником является папка с `SKILL.md` и `skill.yaml`, а не готовый `.skill`-архив. Перед упаковкой проверь frontmatter, ссылки, отсутствие секретов и то, что в архиве нет кэшей, виртуальных окружений или build-output.

Для существующих архивов из `job/skills/` не редактируй ZIP напрямую. Сначала извлеки его в новую исходную папку, проверь содержимое, затем собери новый архив с новым именем/версией. Не перезаписывай опубликованный пакет без прямого указания пользователя.

После изменения запусти валидатор skill-структуры с UTF-8, затем проверь содержимое готового архива и контрольную сумму. Если skill должен автоматически выбираться в Codex, добавь `agents/openai.yaml`; если он опасен или предназначен только для ручного вызова, отключи неявное срабатывание явно.
