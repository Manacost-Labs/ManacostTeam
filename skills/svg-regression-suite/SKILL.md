# Регрессия SVG

Начни с Python-синтаксиса затронутых скриптов, JSON-синтаксиса изменённых specs и `scripts/validate.py` для каждого созданного SVG. Не меняй эталонный результат только ради прохождения сравнения.

Для изменения рендера выбери минимальный набор: затронутый тип, тип с общим шаблоном и тип с data-URI ассетом. Генерируй во временную папку, проверяй отсутствие внешних URL, прозрачный фон вокруг рамки и сходящиеся числа/проценты. Если установлен `resvg`, экспортируй PNG и проверь кадр визуально; иначе отметь проверку пропущенной.

Существующий SyntaxError или сломанный эталон — baseline, а не повод для скрытого попутного исправления. Заводи отдельную задачу с регрессионным тестом.
