# JobTeam

Набор chat-skills для задач найма и оценки вакансий.

| Пакет | Назначение |
|---|---|
| `skills/job-vacancy-evaluator.skill` | Оценка вакансии для соискателя: соответствие цели, деньги, условия, надёжность, рост и красные флаги. |
| `skills/job.skill` | Отбор и оценка авторов игрового контента. |

Пакеты предназначены для импорта в Codex как skills. Вакансии и материалы кандидатов оцениваются прямо в чате; отдельное веб-приложение не требуется.
