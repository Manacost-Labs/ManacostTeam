# Поля и анализ IndexPilot

Правила сняты с исходников плагина IndexPilot (ноябрь 2026). `scripts/seo_check.py`
повторяет стеммер, синонимы, ширину заголовка и слаг плагина; при расхождении
верна панель в WordPress.

## Вкладки метабокса

| Вкладка | Поле | Правило |
| --- | --- | --- |
| Вид в поиске | Заголовок в поиске | До 580 px (Arial 20px), короче 200 px — слишком короткий. Пустое поле — заголовок собирается по шаблону; заполненное выводится как есть, без имени сайта. |
| Вид в поиске | Описание в поиске | 120–155 символов. Пустое — плагин подставит краткий ответ, но анализ даст оранжевый. |
| Вид в поиске | Главный запрос | Одна фраза; по ней идут все проверки ключа. |
| Вид в поиске | Похожие запросы | Через запятую, дубликаты без учёта регистра удаляются, сохраняются первые 4. В анализе не участвуют. |
| Содержание | Краткий ответ | 40–60 слов; HTML вырезается, шорткоды считаются по внутреннему тексту. Счётчик в панели учитывает шорткод как лишнее слово — верна серверная проверка. |
| Содержание | Вопросы и ответы | До 10 пар; пара без вопроса или ответа не выводится. Шорткоды карт в ответах работают на странице, в разметку FAQ идёт их текст. |
| Содержание | Чем считать материал | `Авто`, `Статья` (Article), `Новость` (NewsArticle), `Гайд` (TechArticle), `Без пометки` (выключает проверку краткого ответа). |
| Запросы | — | Данные Search Console и Вебмастера, своих полей нет. |
| Соцсети | Заголовок, описание, картинка | Без лимитов; пустые берутся из поиска. Картинка от 1200 × 630. |
| Дополнительно | Canonical, noindex, слаг рубрики и др. | Трогать только по задаче. |

## Ширина заголовка

Оценка без браузера, px на символ: тире `—`/`–` 20; пробел и `.,:;!|'`ijltfrI()[]` 5,6;
`mwMWжшщмыюЖШЩМЫЮ@%` 16; `г`, `т` 8,6; цифра 11,1; прочая заглавная 13,6;
остальное 10,6. `python scripts/seo_check.py --title-width "Заголовок"`.

## Как плагин ищет ключ

- Текст в нижнем регистре, ё = е, слова — буквы и цифры.
- Игровые синонимы сводятся к одному слову: колода ← дека, сборка, билд,
  деклист, дек; гайд ← руководство, разбор, гид; муллиган ← мулиган, стартовая
  рука; матчап ← противостояние; замена ← альтернатива. Классы: дк → Рыцарь
  смерти, дх → Охотник на демонов, дру → Друид, хант → Охотник, пал → Паладин,
  прист → Жрец, рога → Разбойник, шам → Шаман, лок/варлок → Чернокнижник,
  вар → Воин. Короткие имена совпадают только в перечисленных формах
  («приста» да, «пала» нет).
- Потом русский стеммер: «колоды мага» = «колода мага», «Берн Мага» = «Берн Маг».
- Служебные слова ключа (и, в, на, для, по, от, с, к, о, из, за, у) не
  ищутся. Ключ найден, если все его основы стоят в окне «длина ключа + 2
  слова», начиная со слова ключа: «колода для мага» подходит к «колода мага».

## Анализ: что красное и как исправить

| Проверка | Красное / оранжевое | Исправление |
| --- | --- | --- |
| Ключ в заголовке | Нет ключа — красный; ключ дальше третьего слова — оранжевый | Начать заголовок с ключа. |
| Ключ в описании | Нет — красный | Вписать ключ естественно. |
| Ключ в адресе | Основа каждого слова ключа латиницей должна начинать слово слага | ц → cz, щ → shh, й → j, х → h, ж → zh: «жреца» → `zhrecz…`. У опубликованной записи слаг не менять. |
| Длина адреса | Больше 7 слов или 75 байт — оранжевый | Только для новой записи. |
| Ключ в первом абзаце | Нет — красный | Первый непустой `<p>`; без `<p>` — первые 60 слов. Блок «Коротко» не считается. Дать автору фразу для первого предложения. |
| Ключ в подзаголовке | Ни в одном H2–H4 — оранжевый | Предложить подзаголовок с ключом. |
| Ключ в alt | Ни в одном alt — оранжевый | Alt картинки со списком колоды. |
| Плотность | Норма 0,5–2,5 %; 0 вхождений или больше 2,5 % — красный | Не набивать ключ. |
| Alt картинок | Пустой, равен имени файла или «IMG_1234», «скриншот 2» — красный | Описать изображённое; украшению — пустой alt и `is-decorative`. |
| Ссылки с редиректом | Красный | Подставить конечный адрес. |
| Текст ссылок | «здесь», «подробнее», голый адрес, картинка-ссылка без alt — оранжевый | Текст, по которому ясно, куда ведёт ссылка. |
| H1 в тексте | Красный | Заголовок записи уже H1: понизить до H2. |
| Объём, ссылки, картинки | Меньше 300 слов; нет внутренних ссылок (красный); нет внешних или картинок (оранжевый) | — |
| Краткий ответ | Нет — красный; вне 40–60 слов — оранжевый | — |
| Разделы материала | Нет обязательного H2–H4 — оранжевый | См. ниже. |
| Читаемость | Нет списка или таблицы при 300+ словах, первый абзац длиннее 80 слов, абзац длиннее 150 слов | На оценку SEO не влияет. |
| Профиль автора, миниатюра | Оранжевый | Правится в WordPress, не в статье. |

## Тип материала и обязательные разделы

Тип определяется по заголовку записи и рубрикам, первое совпадение в начале слова:
тир-лист → мета-отчёт → патч (патч, обновлени, нерф, бафф) → муллиган → матчапы →
рубрика «Новости» → гайд (гайд, руководств, как играть) → муллиган вместе с
матчапами или стратегией в H2–H3 → материал.

Заголовок записи гайда со словами «нерф», «обновление», «муллиган» или
«матчап» превращает гайд в другой тип, и проверка разделов гайда пропадает.

Разделы ищутся в H2–H4 по началу слова:

- **Гайд по архетипу**: состав и код колоды (колод, дек, код, состав, сборк,
  список карт); муллиган (муллиган, мулиган, стартов); стратегия (стратеги,
  как играть, план игры, тактик); матчапы (матчап, против); замены (замен,
  альтернатив, бюджет).
- **Мета-отчёт, тир-лист**: список (тир, список, лучшие колоды, топ); что
  изменилось (изменени, что нового, нерф, бафф).
- **Патч**: что изменилось; как повлияет на мету (мет, влияни, что это значит).

Если раздела в статье нет, не выдумывай его: предложи переименовать
существующий подзаголовок, когда он о том же («Против агрессии» уже матчапы),
иначе назови, какого содержания не хватает.

## Формат seo.json

```json
{
  "title": "Берн Маг: масса урона за один ход — гайд от TrueBench",
  "description": "Сетап взрывного урона, менеджмент места в руке и сохранение здоровья — непростые задачи. Со всеми справится только самый умелый Берн Маг.",
  "focus_keyword": "Берн Маг",
  "related": ["ОТК Маг", "Маг на заклинаниях", "гайд на мага", "колоды мага"],
  "answer": "40–60 слов…",
  "faq": [{"question": "Какой муллиган у Берн Мага?", "answer": "…"}],
  "schema_type": "TechArticle",
  "slug": "massa-urona-za-odin-hod-gajd-na-bern-maga-ot-truebench",
  "alts": [{"src": "https://…/deck.png", "alt": "Колода Берн Мага — список карт"}]
}
```

`schema_type`: `""` (Авто), `Article`, `NewsArticle`, `TechArticle`, `none`.
`alts` применяются к картинкам статьи по `src` до проверки.

Команды: `--card` — карточка для копирования; без него — JSON с проверками;
`--slugify "текст"` — слаг по таблице плагина; `--synonyms file.json` — свои
синонимы владельца из настроек плагина (`{"колода": ["дека"]}`). Код выхода 1 —
есть красные пункты, 2 — ошибка входных данных.
