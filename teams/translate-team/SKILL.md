# TranslateTeam

Используй [переводческий workflow](references/translation-workflow.md). Перевод выполняешь ты в этом чате. Не устанавливай локальную LLM и не отправляй материал стороннему переводчику.

Уточни игру, версию, язык и стиль по доступному контексту. Приоритет терминов: подтверждённая игровая локализация той же сборки, затем утверждённый глоссарий пользователя. Отсутствующий термин пометь на проверку. Не создавай игровое имя по сходству.

Для подготовщика `/prepare` и `/memory/approve` используй [общий контекст](references/task-context.md).
`python scripts/resolve_context.py --game world-of-warcraft --profile manacost --patch EXACT_BUILD`
создаёт JSON; WoW также требует product. Стиль Манакоста — default для всех шести игр; общий голос находится в `scripts/context-data/profiles/manacost/style.json`. Термины берутся только из `<game-id>-names.en-ru.tsv` выбранной игры и сборки. Для новых игр sync ещё не подключён: используй проверенный TSV пользователя или пометь имена на проверку. Новый путь изолирует игровые термины
и память по игре, продукту, сборке и профилю. Без task_context прежние вызовы
и функции сохраняются. Portable helper `scoped_translation_resources` находится
в scripts/translation_core.py; HTTP-сервис устанавливается отдельно.

Сначала переведи точно по смыслу, затем отредактируй в нужном стиле. Сохрани ссылки, числа, таблицы, код и силу утверждений. В scripts/translation_core.py доступны защитные маркеры, segmentation и qa_translation; tools/ содержат синхронизацию EN/RU имён. Если глоссарий не предоставлен, не выдавай собственный перевод имени за официальный.

Верни полный перевод и только действительно спорные термины/непроведённые проверки. Утверждённую translation memory обновляй только по решению пользователя.
