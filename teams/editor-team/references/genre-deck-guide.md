# Большой гайд по колоде

Жанровые правила EditorTeam для большого гайда по одной колоде. Общие правила
ядра (граница фактов, проверка содержательности, вычёркивание лишнего, десять
общих owner_checks) действуют полностью; здесь — только то, что добавляет жанр.

## Порядок и форма

Для большого гайда по одной колоде начинай с [шаблона](deck-guide-template.md)
и раздела 6 [стандарта](player-editorial-standard.md). Порядок решений:
вступление-сцена → как работает колода (сразу после вступления, термины
объясняются до первого использования) → карты по ролям → сборки с условием
выбора → муллиган → ранние ходы → разделы мастерства → как играть против →
заключение. Карту описывай ролью, не текстом и не серией абзацев «Карта — …».
У совета есть условие и причина; порядок действий пиши через «>»; указывай, что
можно пропустить новичку. Раздел мастерства пиши только из карточек опыта игрока
(`decision_cards` с `advice_form`): порог и порядок переноси без изменения чисел
и последовательности; нет карточек — раздела нет («писать не из чего»). Первое
лицо только для карточек с `first_person: true`, свой опыт не выдумывай.
Источник называется один раз в конце.

## План и отзыв deck_guide

Режим включается `article_plan.genre = "deck_guide"`: у разделов `role`
(`mechanics` — «как работает колода», входит в `depends_on` зависящих разделов)
и `card_ids` карточек опыта. Для такого плана литературный отзыв возвращает 13
строк `owner_checks`: десять общих и `advice_has_condition_and_reason`,
`mastery_has_threshold_or_order`, `term_before_definition`. Отзыв из десяти
строк читается, но не разрешает новый export. Остальные статьи — прежние десять.

## Типы утверждений (claim_kind)

Только `claim_kind=mechanic` допускает правило с «потому что» при проверенном
основании. Observation — наблюдение в своей выборке, без придуманной причины;
opinion — полезное мнение с именем игрока. Старый claim без типа не классифицируй
по догадке. Если handoff говорит «блок советов писать не из чего», блок не пишется.
Старые runs v1/v2/v3 читаются, но прежние неполные отзывы не разрешают новый
export: создай текущий run, повтори проход и независимые отзывы.
