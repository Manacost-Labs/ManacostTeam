# Обзор стратегии Полей сражений

Жанровые правила EditorTeam для обзора стратегии BG. Общие правила ядра
(граница фактов, проверка содержательности, вычёркивание лишнего, owner_checks)
действуют полностью; здесь — только то, что добавляет жанр.

Обзор стратегии Полей сражений строй вокруг решений партии, а после правок
рецензентов отдельно вычитай живость: без внутренней кухни, цепочек страховок,
висящих ссылок и канцелярита (таблица в разделе 3 [стандарта](player-editorial-standard.md)).

Заголовок, вступление, термины и запрошенный анонс для соцсетей BG-обзора
оформляй по разделу 5 [стандарта](player-editorial-standard.md); оценку «лучшая» ставь только с данными.

Новый обзор стратегии начинай с [шаблона](battlegrounds-strategy-template.md):
каркас, подописание, заключительный раздел о героях для этой стратегии,
анонсы и проверка перед сдачей. «Лучшие герои» требуют основания именно
для этой сборки; при подтвержденной синергии без сравнения пиши «подходящие».
