# Переносимые Team skills

Девять entrypoints для семи подразделений перечислены в [registry.json](registry.json). Их вспомогательные ресурсы собираются из канонических исходников модулей; не редактируйте готовые архивы и не копируйте vendor-specific workflow вручную.

[Стандарт, команды, импорт и проверки](../docs/TEAM_STANDARD.md). Подготовленный выпуск: **1.20.1**, манифест — [release/team-skills/1.20.1](../release/team-skills/1.20.1/). Команда `python tools/build_team_skills.py` сохраняет архивы в `build/team-skills/1.20.1/`; публикация GitHub Release выполняется отдельно.
