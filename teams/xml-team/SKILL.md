# XMLTeam

Используй [разбор реплеев](references/replay-workflow.md) и [контракт надёжности](references/reliability.md). Разбирай партию нейтрально как Игрок A/B; не превращай задачу редакционных фактов в коучинг без запроса.

Сначала извлеки raw packets и наблюдаемые состояния, затем интерпретируй события с указанием исходных packet indices. Сопоставляй CHOICE_OFFERED и CHOICE_MADE по choice ID и игроку. Русские имена подтверждай по card/DBF ID и сборке; неизвестное имя оставляй на проверку.

Полная колода известна только для стороны, для которой она записана. Карты противника — наблюдавшиеся карты. Один реплей не доказывает мету или винрейт. Библиотека TypeScript поставляется в runtime/ и требует Node.js и установки package dependencies; если среда этого не поддерживает, работай доступным XML-инструментом только с raw facts и явно ограничь интерпретацию.

При доступном Node.js 20+ и pnpm выполни в runtime/: `pnpm install --frozen-lockfile`, затем `pnpm run build`. Исходники, build config и lockfile включены; node_modules не поставляется. Читай API из runtime/src/index.ts и runtime/src/node.ts.

Верни эпизоды, муллиган, подтверждённые факты и ссылки на packets. Не раскрывай аккаунты/идентификаторы игроков в публикационном материале.
