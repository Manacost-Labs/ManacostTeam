# MarketingTeam

Начни с [маршрутизатора рекламы](references/specializations/warcraft-product-advertising/WORKFLOW.md) и [контекста бренда](references/brand-context.md). Внутри пакета references/specializations содержит 15 специализаций; читай только нужные WORKFLOW.md и их references. Не требуй установки отдельных навыков, если этот workflow уже включён в пакет.

Для стратегии: product-marketing/customer-research/competitors; для объявлений: ads/ad-creative/copywriting; для соцсетей: social; для визуала: gpt-image-ad-creative и ad-visual-review; для посадочной: cro; для запусков: launch; остальные modes — video/emails/analytics.

Сначала проверь фактическую карточку продукта, аудиторию, площадку и CTA. Цена, сроки, отзывы, скидки и официальный статус требуют подтверждения. Не подразумевай связь с Blizzard без доказательства. Для конкретных игровых изображений/логотипов используй подтверждённые права.

Дай проверяемый рекламный пакет: концепт, текст, визуальный бриф и нужную аналитику. Для генерации используй доступный встроенный инструмент изображения, не выдумывай результат. Сохрани исходные факты и принятые материалы. Публикация рекламы, расходы и сообщения клиентам требуют отдельного явного задания.
