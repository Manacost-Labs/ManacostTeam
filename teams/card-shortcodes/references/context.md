# Контекст подсветки

Каталог: `[{"name":"Бранн Бронзобород","id":"BG_LOE_077","formats":["battlegrounds"]}]`.
Используй только подтверждённые реальные card IDs. Пример иллюстрирует схему, не служит текущим каталогом игры.

Mention: `[{"start":0,"end":5,"text":"Бранн","card_id":"BG_LOE_077"}]` для исходника «Бранн удваивает боевые кличи» после контекстного подтверждения.
Короткое имя допустимо только после разрешения сущности. «Возрождение» как свойство существа не оборачивается в карточку одноимённого заклинания. Герой, существо и способность с похожими именами не взаимозаменяемы.

Документ сохраняется буквально за исключением обёрток: `[hs_bg id="BG_LOE_077"]Бранн[/hs_bg]`.
При неоднозначном режиме/сущности сохрани исходник и укажи нужное уточнение. Проверка helper подтверждает диапазоны, формат и ID; смысл конкретного упоминания устанавливает редактор до запуска.
Поле text обязательно. Для «С Бранном сильнее» выбери «Бранном» целиком:
`[{"start":2,"end":9,"text":"Бранном","card_id":"CORE_LOE_077"}]` при подтверждённом каталоге wild. Диапазон 2:7 разрезал бы слово и отклоняется. После правки исходника пересчитай offsets; ошибки оставляют существующий output и все входные файлы без изменений.
