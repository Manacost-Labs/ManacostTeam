# EditorTeam

Задача — только подсветить реальные упоминания карт. Не переписывай текст, не меняй форматирование, числа, ссылки и порядок абзацев.

Определи игровой режим из задания или явной директивы: standard/wild/arena/battlegrounds. Если его нельзя определить и он влияет на карточку/ID, запроси недостающий режим. Для Battlegrounds используй hs_bg, для остальных — hs_card.

Сверь имена и ID с подтверждённым каталогом соответствующего режима/версии. Никогда не угадывай ID и не подменяй DBF ID строковым card ID. Слова «Монетка», «Размах», «Ярость», «Возрождение» и подобные могут быть обычными словами или механиками: оцени контекст каждого употребления. Для сокращения или падежной формы сначала установи конкретную карту.

Прочитай [контракт и пример](references/context.md). Помощник `python scripts/apply_shortcodes.py SOURCE --catalog catalog.json --format wild --output RESULT` сохраняет весь текст и защищает код, URL, HTML-атрибуты и готовые шорткоды. Для контекстно отобранных употреблений передай --mentions mentions.json с start/end/card_id и исходным text. При наличии mentions вставляются только перечисленные употребления; никаких дополнительных автоматических совпадений. Offset считается в символах исходного текста, а не в байтах.

Каждый mention обязан содержать точный исходный text; start/end охватывают упоминание целиком, включая падежное окончание. После изменения исходника пересчитай диапазоны и снова проверь контекст. Помощник отклоняет несовпадающий text, разрезанное слово и output, совпадающий с любым входным файлом.
Markdown-иллюстрации, определения ссылок и содержимое HTML script/style также сохраняются буквально: подсветка предназначена для видимого текста материала.

Повторный запуск не должен создавать вложенные шорткоды. Неподтверждённые и спорные упоминания оставляй исходными и вынеси отдельным коротким списком. Верни целый текст со шорткодами и число вставок. Не применяй общий WordPress-exporter, если нужен только этот режим: он может изменить HTML/Markdown.
