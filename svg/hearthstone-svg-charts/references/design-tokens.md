# Дизайн-токены HS-Arena для графиков

Источник: дизайн-система HS-Arena (HeartPulse, arena.hs-manacost.ru). Все цвета проверены на пергаментном фоне.

## Палитра

| Токен | Hex | Применение в графиках |
|---|---|---|
| `parchment-light` | `#f7e8bf` | верх градиента пергаментной панели |
| `parchment` | `#ead6a7` | низ градиента пергаментной панели |
| `ink` | `#30251c` | основной текст, значения, оси |
| `ink-muted` | `#735e49` | подписи осей, сетка (с opacity 0.35), сноски, источник данных |
| `wood-dark` | `#2e160b` | внешний край рамки, тонкие разделители |
| `wood` | `#5f371d` | тело деревянной рамки |
| `arena-red` | `#8d171d` | основной цвет данных (серия №1), заголовочная плашка Arena |
| `arena-red-dark` | `#5d0d13` | тёмный край красных элементов, обводка баров |
| `bg-violet` | `#8f536d` | серия №2 / основной цвет для контента Battlegrounds |
| `bg-violet-dark` | `#3d2335` | тёмный край фиолетовых элементов |
| `gold` | `#d9ab49` | ТОЛЬКО мелкие акценты: выделенный бар, звезда лидера, внутренняя окантовка рамки |
| `gold-light` | `#efc96f` | блик на золоте |
| `positive` | `#2f7a3e` | хорошие метрики (винрейт выше среднего, рост) |
| `negative` | `#a33a3a` | плохие метрики (падение, нерф) |

Правила из дизайн-системы, которые нельзя нарушать:
- Золото — никогда как заливка крупных областей (панелей, широких баров всей серии). Только акцент.
- Цвет не единственный сигнал: положительное/отрицательное дублируй знаком (+/−), стрелкой или подписью.
- Иконки классов и арты карт не перекрашивать и не тонировать фильтрами.

## Порядок цветов для серий данных

1. `#8d171d` arena-red
2. `#8f536d` bg-violet
3. `#2f7a3e` positive-green
4. `#b98a2f` тёмное золото (только если серий ≥4)
5. `#735e49` ink-muted

Больше 5 серий на одном графике не делать — разбей на два графика.

Стандартные цвета классов WoW/HS слишком светлые для пергамента (Priest белый, Rogue жёлтый). Используй затемнённые варианты + обводку `#30251c` толщиной 1:

| Класс | Hex | Класс | Hex |
|---|---|---|---|
| Друид | `#a05a10` | Разбойник | `#b0a231` |
| Охотник | `#5e7a2f` | Шаман | `#1e4e8c` |
| Маг | `#2a7fa5` | Чернокнижник | `#6a4a8c` |
| Паладин | `#c9722f` | Воин | `#8c3a2a` |
| Жрец | `#8a8578` | Рыцарь смерти | `#3f6f6a` |

Идентичность класса всегда дублируй иконкой (см. `assets/class-*.webp`) — цвет вторичен.

## Типографика

| Роль | font-family | Размер (в ед. viewBox 800) | Прочее |
|---|---|---|---|
| Заголовок графика | `HSDisplay, Georgia, serif` | 24–28, weight 700 | letter-spacing 0.5; тёмная обводка `paint-order="stroke"` |
| Подзаголовок / период | `Georgia, serif` | 14–15, style italic | цвет ink-muted |
| Названия классов/строк, значения, заголовки колонок | `HSDisplay, Georgia, serif` | 14–15 | игровой Belwe, вшивается сабсетом |
| Подписи осей, мелкие пометки | `Inter, -apple-system, 'Segoe UI', sans-serif` | 13–14 | ink или ink-muted |
| Сноска / источник | тот же sans | 11–12 | ink-muted, единственное место где можно <13 |

HSDisplay — это Belwe Bold с кириллицей (`assets/fonts/`), родной шрифт Hearthstone. Генератор вшивает его сабсет прямо в SVG через `@font-face` с data-URI — работает даже при вставке через `<img>`, сети не требует. Фолбэки всё равно обязательны: сабсет покрывает только заголовки; если fonttools недоступен, всё тихо падает в Georgia — проверяй макет и в фолбэке. PNG-экспорт подключает шрифт флагом `--use-font-file` сам.

## Геометрия

- viewBox: `0 0 800 450` (стандарт), `0 0 800 500` (с легендой снизу), `0 0 800 560` (10+ строк баров). Без атрибутов width/height на `<svg>` — график резиновый.
- Сетка отступов: 8. Все координаты кратны 4, лучше 8.
- Рамка: 16–20 единиц толщиной. Поле между рамкой и контентом: 24–32.
- Минимальный кегль 13 (кроме сноски). Если подписи не влезают — увеличь viewBox по высоте, а не уменьшай шрифт.
- Толщины линий: сетка 1 (opacity 0.3), оси 1.5, линии данных 2.5–3, обводка баров 1.
- Скругления: бары 3, панели 8–12, `stroke-linecap="round"` и `stroke-linejoin="round"` на линиях данных.
