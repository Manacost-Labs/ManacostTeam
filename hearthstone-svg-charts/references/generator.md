# Генератор make_chart.py — справочник JSON-спеков

## Живые данные — сначала from_api.py

Для меты, Арены, Полей сражений и дайджеста сайта НЕ собирай спек руками — есть готовые команды (данные с api.kolodahearthstone.com и hs-manacost.ru):

```bash
python3 scripts/from_api.py meta --png                      # топ-10 меты барами
python3 scripts/from_api.py scatter                         # карта меты (винрейт × популярность)
python3 scripts/from_api.py history --archetype "Pirate Warrior"
python3 scripts/from_api.py arena-tiers / arena-donuts
python3 scripts/from_api.py bg-tiers / bg-radar --hero "Cariel Roame"
python3 scripts/from_api.py arena-legendaries --top 10
python3 scripts/from_api.py versus --left "Pirate Warrior" --right "Attack Druid"
python3 scripts/from_api.py digest --days 7
```

Общие флаги: `--png`, `--social square|story`, `--out DIR`, `--title` (например, русское имя героя для радара). Ручной спек нужен только для данных, которых нет в API.

## Произвольные данные (исследования, опросы, Reddit, свои таблицы)

Любые данные превращаются в SVG одним вызовом — спек можно даже не писать в файл:

```bash
echo '{"type":"bars","title":"...","data":[...]}' | python3 scripts/make_chart.py - -o chart.svg
```

или из Python: `import make_chart; svg = make_chart.build(spec_dict)`.

Правила, когда данные собирает/выбирает ИИ (исследование сообщества, парсинг Reddit, чужие опросы):
1. Сам выбери тип по форме данных: рейтинг → `bars`, доли одного целого → `donut`, состав нескольких строк → `stackbars`, две метрики на объект → `scatter`, профиль по осям → `radar`, динамика → `line`.
2. В footer ОБЯЗАТЕЛЬНО: источник, период, размер выборки и метод («топ-100 постов r/BobsTavern за неделю, категории — флейры Reddit»). Читатель должен видеть, откуда цифры.
3. Ничего не выдумывай и не сглаживай: если категория «прочее» — так и пиши; если выборка мала — скажи в сноске.
4. Суммы долей — ровно 100; проценты с одним знаком.

**stackbars** — 100%-стек по строкам с лентами перетекания между соседними строками (мини-санкей): состав чего-либо в нескольких разрезах (посты/апвоуты/комментарии по темам; за/против по сегментам аудитории). Ленты — главный сюжет: где тема раздувается, где сжимается. Сегменты с одинаковыми `name` красятся одинаково («Прочее» — всегда приглушённый песочный), легенда сверху с переносом, у строки опциональный `sub` — сумма в абсолюте под подписью. Порядок строк выбирай осмысленно: перетекание читается между соседями.
```json
"data": [{"label": "посты", "sub": "92 шт.", "segments": [{"name": "мемы", "value": 34}, ...]},
         {"label": "комментарии", "sub": "2 545", "segments": [...]}],
"colors": {"мемы": "#b98a2f"}
```

Детерминированный путь: данные пользователя → JSON-спек → готовый SVG. Вся арифметика (шкалы, координаты, перенос текста, цвета матрицы) — в скрипте, ошибиться негде.

```bash
python3 scripts/make_chart.py spec.json -o chart-<тема>-<yyyymmdd>.svg
python3 scripts/export_png.py chart.svg          # → PNG 2x, прозрачность сохраняется
```

## Общие поля спека

| Поле | Значения | По умолчанию |
|---|---|---|
| `type` | bars, line, donut, tierlist, beforeafter, matchup, badge, timeline, digest | обязательно |
| `title` / `subtitle` | строки | subtitle опционален |
| `footer` | строка, добавляется к автосноске о шкале | — |
| `theme` | `arena` (красный) / `bg` (фиолетовый) | arena |
| `frame` | `vector` / `authentic` (9-slice рамка из игры) | vector |
| `vmin`, `vmax`, `unit` | шкала и единица для числовых типов | авто, `%` |
| `finish` | `parade` (пятна пергамента, полный декор) / `quiet` (тише, для врезок) | parade; badge и digest — quiet |
| `logo` | `true`/`false` — логотип MANACOST внизу справа (`assets/site-logo.png`, добавляется полоса +52) | true (кроме badge) |
| `dedupe` | `true` — повторяющиеся картинки через `<symbol>`/`<use>` (минус 20–40 КБ на файл). По умолчанию выключено: WordPress и часть вьюеров не показывают `<image>` внутри `<use>` — иконки пропадают, остаются пустые рамки | false |
| `animate` | `true` — CSS-анимация появления (строки всплывают каскадом, бары растут). Работает при инлайн-вставке SVG и открытии файла в браузере; через `<img>` и в PNG показывается конечный кадр, ничего не ломается | false |
| `format` | `wide` / `square` (1:1, VK/TG) / `story` (9:16) — контент центрируется по вертикали; если пустых полей выйдет больше 60% высоты контента, генератор откажет (возьми больше строк или другой тип) | wide |

Дизайн-детали, которые генератор делает сам (не воспроизводи вручную без нужды): вшивает сабсет шрифта HSDisplay (Belwe с кириллицей, ~15–25 КБ; нужен `pip install fonttools brotli`, без них — молча Georgia); заголовок — лента красного сукна (`arena-rail-red.jpg` паттерном) с ласточкиными хвостами и обводкой текста; рамка — бевелы, золотые уголки, мягкая тень предмета; бары — внутренний бевел, у лидера золотая гемма на конце и медальон со значением; пергамент — пятна выцветания (parade) и прижжённые края.

`icon` в любом месте: слаг класса (`mage`, `deathknight`…), `tribe-murlocs`, `bg-tier3`, `rarity-epic`, `mana`, `bg-hero-<Имя>` (скачай сначала: `fetch_assets.py --bg-hero "Имя"`) или путь к локальному файлу (будет ужат и вшит data-URI).

## Спеки по типам

**bars** — горизонтальные бары (винрейты, популярность). Сортирует сам, лидера выделяет золотом, среднюю линию рисует при 3+ строках (`"average": false` — отключить). Колонка подписей растягивается под самое длинное имя (до 320), сверхдлинные обрезаются с «…». Вторая метрика — текстовой колонкой справа: `"extra_header": "популярность"` в спеке + `"extra": "9.7%"` в строках.
```json
"data": [{"label": "Маг", "icon": "mage", "value": 58.2, "extra": "12.4%"}, ...]
```

**line** — динамика. 1 серия — с градиентной заливкой, 2+ — легенда автоматически. Метки X прореживаются до ~7.
```json
"data": {"xlabels": ["33.0", "33.2"], "series": [{"name": "Маг", "values": [9.5, 14.8]}]}
```

**donut** — доли (сумма строго 100, иначе скрипт откажет). `center` — число и подпись в центре.
```json
"data": [{"label": "Мех-паладин", "value": 28}, ...], "center": {"big": "12 480", "small": "игр в выборке"}
```

**tierlist** — группы S/A/B/C/D. `colheaders` — заголовки числовых колонок (1–2).
```json
"colheaders": ["винрейт", "выбор"],
"data": [{"tier": "S", "rows": [{"label": "Маг", "icon": "mage", "cols": ["58.2%", "12.4%"]}]}, ...]
```

**beforeafter** — пары «до/после» с дельтой ▲/▼. `labels` — подписи легенды (по умолчанию до/после патча).
```json
"data": [{"label": "Мех-паладин", "before": 52.1, "after": 56.3}, ...]
```

**matchup** — матрица винрейтов строка-против-столбца. `null` — прочерк (зеркальная ячейка/диагональ). Цвет дивергентный: vmin красный → 50 нейтральный → vmax зелёный.
```json
"data": {"rows": [{"label": "Маг", "icon": "mage"}, ...], "cols": [так же],
         "values": [[null, 52.4], [47.6, null]]}
```
До 7 столбцов с иконками читаемо; 11×11 влезает, но цифры мельчают — для полной матрицы предупреди пользователя.

**badge** — компактная врезка 320×132 в золочёной рамке deck-border, без заголовочной плашки. Для лидов статей и соцсетей.
```json
"data": {"value": "67.3%", "label": "винрейт за 320 игр", "icon": "paladin"}
```

**facts** — полоса «факты»: 2–4 медальона с крупным числом (Belwe) и подписью, опциональные иконка и `tone` (`pos` зелёный / `neg` красный оттенок значения), `note` — строка-вывод под медальонами. Для текстов, где цифр мало и они точечные («4.6% меты, >61% винрейт»). Значение может быть и символом (▲/▼), если факт качественный — но не выдумывай числа.
```json
"data": [{"value": "4.6%", "label": "меты — обе версии", "icon": "warlock", "tone": "pos"}, ...],
"note": "На большей дистанции сборки сохранили результат."
```

**character** — бейдж персонажа для лор-статей: арт слева в золотой рамке (любой локальный файл или арт карты; кроп по центру), справа таблица «параметр — значение» (подписи капсом красным, значения до 3 строк), подпись под артом через `caption`. Имя персонажа — в `title`. Арт карты Hearthstone можно взять с HearthstoneJSON: `https://art.hearthstonejson.com/v1/orig/<card_id>.png` (id — через `cards.collectible.json` по русскому имени).
```json
"data": {"art": "/путь/арт.png", "caption": "арт: Hearthstone, «Альтеракская долина»",
         "rows": [{"label": "Раса", "value": "Человек"}, {"label": "Класс", "value": "Маг"}]}
```

**author** — карточка автора для подписи статей: круглый аватар в золотом кольце, имя (Belwe), роль, тэглайн до 2 строк, до 3 стат-пилюль. Без заголовочной плашки и логотипа, finish quiet.
```json
"data": {"name": "Zulut", "role": "автор и редактор hs-manacost.ru",
         "avatar": "/путь/к/фото.jpg", "tagline": "Пишу про Арену и Поля сражений.",
         "stats": [{"value": "480+", "label": "статей"}, {"value": "топ-1%", "label": "Арена"}]}
```

**versus** — афиша «кто кого»: два портрета в золотых кольцах, VS-медальон, встречные бары по метрикам (победитель — насыщенный цвет, золотая обводка и ★; проигравший — приглушён). `better: "lower"` — когда меньше = лучше (длина игры). Нечисловые значения выводятся текстом без баров.
```json
"data": {"left": {"name": "Пират Воин", "avatar": "warrior", "color": "#8d171d"},
         "right": {"name": "Друид на атаке", "avatar": "druid"},
         "metrics": [{"label": "винрейт", "left": 61.1, "right": 59.3, "unit": "%"},
                     {"label": "длина игры", "left": 6.0, "right": 9.0, "better": "lower"}]}
```

**quote** — цитата-карточка: золотые кавычки, текст Belwe до 5 строк, автор с круглым аватаром и ролью, источник в footer. Без плашки, finish quiet. Цитаты не выдумывать — только реальные слова реальных людей (или от имени сайта).
```json
"data": {"text": "…", "author": "Manacost", "role": "мета-отчёт Арены", "avatar": "/путь/фото.jpg"}
```

**mulligan** — мулиган-гайд: строки — карты (кристалл маны со стоимостью + имя), столбцы — классы-оппоненты (иконки, до 7), в ячейках вердикты `keep` ✓ / `if` ? / `toss` ✗. Вердикты — редакционные, их пишет автор.
```json
"data": {"opponents": ["priest", "druid", "warrior"],
         "rows": [{"card": "Факел", "cost": 1, "verdicts": ["keep", "keep", "if"]}]}
```
Декодер кода колоды: `scripts/deckstring.py` (dbfId → имена через /api/v1/constructed-cards/by-dbf/).

**scatter** — карта меты по методологии hearthpulse: X — винрейт, Y — популярность, размер точки — число игр, цвет — класс (палитра классов под пергамент), пунктир на 50%. Подписи топ-N (по играм) с авторазруливанием коллизий.
```json
"data": [{"label": "Пират Воин", "x": 61.1, "y": 9.1, "games": 24396, "class": "warrior"}, ...],
"label_top": 8
```

**radar** — паутинка 3–8 осей, значения 0–100 (нормируй сам: min-max по пулу сравнения, укажи это в footer). До 2 серий; вторая с `"reference": true` рисуется пунктиром без заливки (эталон для сравнения).
```json
"axes": ["Место", "Топ-4", "Победы", "Выживание", "Выбор"],
"data": [{"name": "Cariel Roame", "values": [98, 95, 60, 97, 45]},
         {"name": "медианный герой", "values": [50, 50, 50, 50, 50], "reference": true}]
```

**timeline** — горизонтальная ось событий (история или roadmap). `status`: `done` (зелёный), `now` (золотой ромб), `major` (красный), `planned` (контур). Подписи чередуются верх/низ. 4–7 событий оптимально.
```json
"data": [{"date": "30 авг", "label": "Патч 33.4", "status": "now"}, ...]
```

**digest** — «вышло за неделю»: миниатюра в золотой мини-рамке + чип рубрики + заголовок + дата. `image` — иконка-слаг или путь к обложке статьи (локальный файл; фото всегда пережимается в JPEG ~45 КБ); без image — плейсхолдер с кристаллом маны. `url` у элемента делает миниатюру и заголовок настоящей ссылкой (`<a href>`) — работает при инлайн-вставке SVG на сайт; from_api проставляет ссылки статей сам. `theme` у элемента красит чип (`"bg"` → фиолетовый). При 7+ материалах автоматически включается компактный режим (мелкие миниатюры, заголовок в одну строку с обрезкой) — форсируется полем `"compact": true/false`. Разумный максимум: 6 полных или 10–12 компактных строк.
```json
"data": [{"image": "/path/cover.jpg", "title": "Гайд на Алекстразу", "category": "Поля сражений", "theme": "bg", "date": "29 авг"}, ...]
```

## Когда генератора мало

Нестандартный график (мана-кривая, scatter, карта…) — собирай SVG вручную по `templates.md` + `frame.md`, но чекпоинты те же: validate.py, checkerboard.py, глаза.
