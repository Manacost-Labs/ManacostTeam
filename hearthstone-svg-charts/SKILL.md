# Hearthstone SVG Charts

Графики для статей по Hearthstone: пергаментная панель в деревянной рамке, снаружи рамки — прозрачность. График выглядит как предмет из игры, лежащий на странице статьи, и работает на любом фоне.

## Порядок работы

1. **Данные.** Возьми данные пользователя как есть. Ничего не выдумывай: не хватает чисел — спроси. Проверь сумму долей (=100) и правдоподобие (винрейт 0–100).
2. **Тип.** Подбери тип по таблице ниже. Прочитай `references/generator.md` (спеки JSON) — этого достаточно для стандартных типов; `design-tokens.md`, `frame.md`, `templates.md` читай при ручной вёрстке или вопросах по стилю.
3. **Живые данные?** Мета, Арена, герои/тиры Полей сражений, история архетипа, дайджест статей сайта — всё это одна команда `scripts/from_api.py` (см. верх `generator.md`), данные придут сами из api.kolodahearthstone.com / hs-manacost.ru. Спек руками — только для данных, которых нет в API.
4. **Сгенерируй через скрипт** (не вручную — арифметику шкал и координат считает он):
   ```bash
   python3 scripts/make_chart.py spec.json -o chart-<тема>-<yyyymmdd>.svg
   ```
   JSON-спек пиши сам из данных пользователя. `theme`: arena (красный) / bg (фиолетовый) — по теме контента. `frame: "authentic"` — для заглавных графиков. Иконки классов/типов/тиров/редкостей уже в assets; портрет героя BG докачай: `scripts/fetch_assets.py --bg-hero "Имя"`. Если каталог assets пуст — сначала `scripts/fetch_assets.py`.
   Нестандартный график (мана-кривая, scatter…) — ручная вёрстка по `templates.md` + `frame.md`, правила те же.
4. **Проверь статически:** `python3 scripts/validate.py chart.svg` — ERRORs исправляй обязательно.
5. **Проверь визуально — не пропускать:** `python3 scripts/checkerboard.py preview.html chart.svg`, открой в браузере, посмотри сам: шахматка видна ВОКРУГ рамки на светлом и тёмном; текст не пересекается и не обрезан; колонка 360px читаема. Генератор надёжен, но длинные строки пользователя — нет. Нашёл проблему: если она в данных/спеке — поправь спек; если в самом рендерере — почини `make_chart.py` (это скилл-инструмент, его можно и нужно улучшать).
6. **PNG при необходимости** (соцсети, Telegram): `python3 scripts/export_png.py chart.svg` (нужен `brew install resvg`). Открой PNG и проверь шрифты — Cinzel в PNG заменяется Georgia.
7. **Отдай пользователю** файл(ы) + одной строкой: тип, режим рамки, размер, «фон прозрачный, проверено на светлом/тёмном».

## Выбор типа

| Запрос | type |
|---|---|
| винрейты/популярность классов, героев, архетипов | `bars` |
| динамика по патчам/дням, история меты | `line` |
| доли (архетипы, редкости, типы существ) | `donut` |
| тирлист картинкой | `tierlist` |
| что изменил патч/нерф | `beforeafter` |
| кто кого контрит, таблица матчапов | `matchup` |
| одно число-факт для врезки/соцсетей | `badge` |
| история событий или дорожная карта сезона | `timeline` |
| «что вышло за неделю», подборка статей | `digest` |
| «карта меты», сила против популярности | `scatter` |
| профиль героя BG по осям, «паутинка» | `radar` |
| «что держать в мулигане», карты × оппоненты | `mulligan` |
| 2–4 точечные цифры из текста, «три факта» | `facts` |

Для VK/Telegram: `"format": "square"` (1:1) или `"story"` (9:16) — или флаг `--social` у from_api.py.
Для инлайн-вставки на сайт: `"animate": true` — анимация появления; у digest поле `url` делает строки кликабельными.

## Жёсткие правила

- Прозрачность: никакого фона на весь viewBox, никакого `background` на `<svg>`, никаких белых плашек под текстом. Текст нечитаем — двигай текст.
- Только data-URI и `#`-ссылки внутри SVG. Внешний URL молча не отрисуется в статье.
- `viewBox` без `width`/`height` на корне.
- Точность важнее красоты: значения на графике сходятся с данными пользователя до последней цифры. Спек — копия данных, не пересказ.
- Золото `#d9ab49` — только мелкие акценты (правило дизайн-системы HS-Arena).
- Иконки классов/героев/редкостей не тонировать и не обрезать.
- Проценты с одним знаком после точки: `54.3%`. Дельты всегда со знаком и стрелкой ▲/▼ — цвет не единственный сигнал.

## Словарь (термины сайта)

- Arena **runs** — «походы» (или «заявки»), не «забеги».
- **Underground Arena** — «Подпольная Арена», не «подземная».
- Сила легендарок Арены — **очки** (score hearthpulse), винрейт колод — вторичная метрика.
- Названия карт и архетипов — как на hearthpulse.net / hs-manacost.ru.

## Файл на выходе

Имя: `chart-<тема>-<yyyymmdd>.svg`. Один график = один файл. Размер: векторный <30 КБ; с иконками/рамкой из игры <200 КБ (дайджест с обложками — до 300 КБ). Больше — ужми обложки (это делает `inline_image` сам) или убери текстуры.

В `examples/` — проверенные примеры каждого типа со спеками (`examples/specs/`): при сомнениях сверяйся.
