# Инструменты MarketingTeam

Используй только инструменты, реально доступные в текущем чате. Для поиска фактов нужны доступный веб-поиск и открытие первоисточников; для изображения — встроенная генерация изображений. Ссылка на этот реестр не означает подключение рекламного кабинета, CRM, почты или аналитики.

Числа из рекламных кабинетов, продаж и аналитики получай из предоставленного экспорта или явно подключённого сервиса. Указывай источник и период. Без данных предложи схему измерения и шаблон, не выдумывай результаты. Изменять кампании, тратить бюджет и отправлять сообщения можно только по явному заданию владельца.
