# Ad Visual Review

Review the actual image, not only its prompt. Read [`../../brand-context.md`](../../brand-context.md), the product brief, and any campaign copy. If the file is local, inspect it with `view_image` before assessing it.

## Check in this order

1. **Product truth:** the item is recognisable and its visible material, configuration, branding, and included parts match the approved source.
2. **Message and attention:** the focal point reads at a small size; the visual has a clear hierarchy and usable space for copy or CTA.
3. **Rendered text:** every in-image word, price, date, claim, and code is legible and matches the approved source exactly. Flag it for external typesetting if it does not.
4. **Game/IP safety:** no unapproved Blizzard logo, character art, screenshot, card frame, game UI, or implication of official affiliation. Read [`../warcraft-product-advertising/references/claim-and-brand-safety.md`](../warcraft-product-advertising/references/claim-and-brand-safety.md) for claims that need proof.
5. **Placement:** orientation, crop, and safe space fit the named channel. If it is unnamed, state that placement compliance remains open instead of guessing.

## Report

Return a compact table: `Status` (pass / needs edit / blocked), `issue`, `why it matters`, and `precise change`. Separate blocking factual or rights issues from ordinary art-direction changes. End with one of: `ready for copy placement`, `regenerate with these constraints`, or `needs evidence before use`.

Do not call an image launch-ready while a price, legal statement, game claim, or asset right is unverified. Do not publish or upload the creative.
