# Claims and brand-safety check

Read this file before drafting a final advertisement, comparison, landing page, or visual brief that refers to Blizzard, Hearthstone, Warcraft, a current patch, or in-game material.

## Claim classes

| Claim | Minimum evidence before publishing |
| --- | --- |
| Product name, price, stock, discount, delivery, returns | Current product card or operator confirmation |
| Compatibility, material, size, digital entitlement | Product specification or fulfilment documentation |
| Review, customer count, performance, scarcity | Traceable source that supports the exact wording and date |
| Current patch, expansion, card/mode availability | Current primary game source |
| Official, licensed, partner, endorsed | Written authorisation or a source that explicitly establishes it |
| Image, logo, screenshot, character art | Confirmed licence, permission, or approved asset record |

## Copy boundaries

- Describe a connection precisely: “для поклонников Warcraft” is different from “официальный товар Warcraft”. Use the latter only with proof.
- Do not imply the seller is Blizzard Entertainment or is endorsed by it merely through colour, logo placement, wording, or a CTA.
- Do not promise an outcome that depends on the game, player skill, a patch, availability, or a third party.
- Use real urgency only: a documented end date, limited stock count, or confirmed delivery cutoff. Otherwise remove urgency wording.

## If evidence is missing

Use a neutral placeholder, for example `[НУЖНО ПОДТВЕРДИТЬ: срок скидки]`, and list the required source in the pre-launch check. Suggest an original visual direction rather than reusing an unverified game asset.
