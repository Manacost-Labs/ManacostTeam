# Warcraft Product Advertising

Turn a confirmed product brief into a platform-ready advertising package for a Hearthstone or Warcraft audience without pretending an official affiliation or inventing proof.

## Start with the factual boundary

Read [`../../brand-context.md`](../../brand-context.md) and, if present, `../../../.agents/product-marketing.md`. Extract what is actually confirmed about the item, audience, price, fulfilment, landing page, assets, game references, conversion event, budget, and channels.

If a fact materially changes the ad, identify it as `[НУЖНО ПОДТВЕРДИТЬ: ...]`. Do not turn missing information into an assumption. For current game or market claims, research and cite a current primary source before using the claim.

Before recommending a creative that uses game art, logos, names, screenshots, or a Blizzard relationship, read [claim-and-brand-safety.md](references/claim-and-brand-safety.md).

## Produce the smallest useful package

Choose the deliverables that fit the request. A campaign package normally contains:

1. a one-paragraph offer and audience summary, with confirmed versus open facts;
2. a selected channel and conversion event, with a budget hypothesis rather than invented performance forecasts;
3. 3–5 distinct creative angles, each tied to a real product benefit or proof;
4. platform-specific ad copy and CTA, with character limits when the platform is named;
5. landing-page message match and UTM / conversion-measurement requirements;
6. a pre-launch check: evidence, usage rights, price and fulfilment, audience exclusions, tracking, and platform-policy review.

For a single request, create only the asked-for part. Keep strategy, drafts, and measurement plans separate from any external publishing action.
