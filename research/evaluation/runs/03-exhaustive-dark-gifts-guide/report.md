## Key finding

A professional guide cannot copy the July developer explainer as a timeless rules table. Patch 36.2.1 changed windows, bans, weighting and bugs; patch 36.2.2 changed the system again. Patch 36.4 was checked and adds no later Dark Gift rule delta. Current wiki and specialist databases provide viable enumeration inputs, but they have not yet been audited item by item in this run.

## Required continuation

1. Build the 43-row evidence matrix: gift, effect, min/max turn, conditions, exclusions, hero pool, primary source, superseding patch, verification status.
2. Build a compatible-minion/invalid-combination matrix.
3. Add current expert and statistical evidence or explicitly preserve the evidence gap.
4. Run controlled tests for shared-copy behavior and other undocumented edge cases.
5. Produce and visually QA the final guide.
