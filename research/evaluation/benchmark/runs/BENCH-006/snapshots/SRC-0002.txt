The Responses API has a 30-day Application State retention period by default, or when store is true; response data is then stored for at least 30 days.
When Zero Data Retention is enabled for an approved organization, store is always treated as false for Responses and Chat Completions even if a request sends true. Some endpoint capabilities may still have separate eligibility limits.
