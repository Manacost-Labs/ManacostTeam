# Research Report

Research ID: `RES-20260828T085550Z-F87DBC20`

There is no evidence-backed universal first-use turn. Spend the first Dark Gift when the current 3-Gold shop action is weak or immediate tempo is more valuable than waiting. If the board is stable, preserving the option into turns 4-6 improves official offer bands and unlocks the turn-6 tribe-match guarantee.

Current community discussion repeatedly uses this state-based logic, but public HSGuru/HSReplay decision-level timing data was not found. Therefore the turn 4-6 pattern is a conditional heuristic, not a statistical optimum. Recheck exact advice after balance changes; patch 36.2.2 materially changed gifts.
