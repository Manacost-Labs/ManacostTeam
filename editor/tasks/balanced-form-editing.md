База: clean main 02de87d, код v11 9bbe601. Gate A: GPT-6 Luna по запросу
владельца; read-only. Область — Go prompts анализа, автора и critic.
Канонические EditorTeam, Go language/testing и monorepo gate применимы.
Server skillctl/ai-check, Serena/codegraph в этой Windows-сессии недоступны;
используются локальные rg, Go test/vet/build и воспроизводимый живой API опыт.

Гипотеза: общий призыв минимизировать редактуру и отсутствие положительного
контракта формы заставляют writer недоредактировать правильные мысли.
Reader_problem может быть тяжёлой формой, а не отсутствующей информацией.
Новое объяснение проверяется по соседнему контексту: уже ясное правило не
должно появляться второй раз. Это гипотеза о prompts, не установленная
причина каждого модельного выбора.

Защиту смысла проверяют существующие регрессии; качество текста — реальные
ответы и слепые отзывы. Этот известный набор не является новым holdout.

неисправность локализована в Go layer, ZIP 1.11.0 остаются прежними.
