# Логотип ManacostTeam

`manacost-team-logo.png`: 1254 × 1254, RGBA PNG. Используется в корневом
README и как `faviconPath` проекта ManacostTeam в T3. В T3 указан абсолютный
локальный путь; на другой машине его нужно назначить для своей рабочей копии.

Создан 5 ноября 2026 встроенным `imagegen`, без CLI/API fallback.
Знак: редакционные карточки образуют M, в центре — кристалл.
Исходный PNG скопирован без редактирования, alpha сохранена.
