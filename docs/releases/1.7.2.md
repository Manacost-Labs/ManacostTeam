# ManacostTeam 1.7.2 — 15 октября 2026

Выпуск объединяет актуальные переносимые навыки семи Teams и установочные
материалы. Основное изменение — проверка редакторских утверждений с учётом
исходника во всех поддерживаемых редакторских маршрутах.

## Изменения

- **EditorTeam 1.7.2:** единая проверка фактов для `/edit`, AG-UI и `/v2/edit`,
  всех глубин правки и `EDITOR_REVIEW_MODEL`. Неподтверждённые редакторские
  добавления отклоняются. Go reviewer проверяет сохранение уверенности
  и цитаты для medium/low; critic отклоняет недостаточное сохранение фактов
  и смысла, а также неизвестные уровни severity.
- **ResearchTeam 1.3.1 и Manacost Publish 1.1.1:** сохранённые источники,
  хеши, проверка цитат и актуальный смысловой аудит образуют проверяемую
  передачу материала между исследованием, редактурой и экспортом.
- **Общий контекст:** выбор игры и редакционного профиля, профиль Манакоста,
  изоляция словарей и памяти переводов; **TranslateTeam 1.2.1**.
- **Установка:** установщик навыков для агентов, серверный Compose, API
  с токеном и WordPress-плагин 1.0.0 с ручным применением результата.
  Исправлены Windows UTF-8, воспроизводимость ZIP и завершение соединений API.
  Перед публикацией дополнительно исправлено чтение метаданных и Compose
  в системной кодировке cp1251: установщик теперь явно использует UTF-8.
- Страница загрузок теперь ведёт на актуальные пакеты; все прежние выпуски
  и байты пакетов 1.7.2 сохранены.

## Состав и установка

В GitHub Release приложены девять ZIP с идентичными `.skill` aliases,
`manacost-team-1.7.2-plugin.zip`, `index.json`, `SHA256SUMS`
и отдельный `manacost-team-wordpress-1.0.0.zip`.
`SHA256SUMS` покрывает архивы навыков и combined plugin; WordPress-пакет
поставляется отдельно и в этот список не входит.

[Скачать релиз](https://github.com/Manacost-Labs/ManacostTeam/releases/tag/v1.7.2).
[Выбрать отдельный навык](../../release/team-skills/README.md).
[Инструкция установки](../INSTALL.md).

## Совместимость и обновление

Контракты запросов и JSON/SSE старых редакторских клиентов сохранены.
При ручной установке замените папку нужного навыка новой версией по
инструкции установки. Пользовательские материалы и старую память переводов
переносить или удалять не требуется. Неизменённые навыки сохраняют прежние
версии; номер всего выпуска определяется `teams/registry.json`.

Пакеты не предоставляют API-ключи, платные вызовы или отсутствующий runtime.
XML source kit требует Node.js, pnpm и установки зависимостей.

## Проверки и ограничения

Для исходного кода `a8161a5` подтверждены успешные GitHub
[Editor CI](https://github.com/Manacost-Labs/ManacostTeam/actions/runs/38655305407)
и [Portable Team skills](https://github.com/Manacost-Labs/ManacostTeam/actions/runs/38655305422).
Editor CI включает Python на Windows/Linux/macOS, Go, NLP sidecar,
deterministic eval contract и Docker/E2E. Упаковка и XML source kit
проверены на Windows и Ubuntu.

Перед публикацией на Windows повторно выполнены:

- `python -m unittest discover -s tests -p 'test_*.py'`: 62 теста,
  61 прошёл, один пропущен. `test_symlink_destination_is_rejected`
  недоступен без права создания симлинков; проверка обхода путей в ZIP
  выполняется отдельно и прошла.
- `test_agent_cli_uses_explicit_utf8_for_metadata`: воспроизвёл сбой
  до исправления и прошёл после него при `PYTHONUTF8=0` и запрете неявной
  кодировки. Установка в папку с кириллицей и выбранный контекст проверены.
- `python tools/build_team_skills.py --check`: семь Teams, девять навыков,
  точный состав и воспроизводимые байты всех архивов подтверждены.
- `python tools/smoke_xml_skill.py`: установка зависимостей, сборка
  из распакованного XML ZIP и разбор минимального реплея прошли.
- Ссылки на файлы, версии девяти навыков и `git diff --check` проверены.

Эти проверки подтверждают код и упаковку; актуальность игровых источников,
достоверность будущих ответов модели и работу в реальном WordPress
они не подтверждают. Подробности предыдущего полного аудита и известных
ограничений — [отчёт за 14 октября](../AUDIT_2026-10-14.md).
