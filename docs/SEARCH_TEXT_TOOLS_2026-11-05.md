# Инструменты для поиска и качества текста

Проверены 5 ноября 2026 по первичным README/документации. Это кандидаты
для отдельных измеримых экспериментов, не заявление о приросте качества.
Кроме Potato, новые инструменты не устанавливались. Источники:

| Инструмент | Что проверено и где применить | Ограничения / проверка перед внедрением |
| --- | --- | --- |
| [SearXNG](https://github.com/searxng/searxng) | Self-hosted метапоиск по нескольким движкам; [HTTP/JSON API](https://docs.searxng.org/dev/search_api.html). Дополнительное обнаружение источников | Самостоятельный сервис, ограничения движков и блокировки. JSON нужно включить; публичные instances часто его отключают. Не заменяет Scrape.do-first и не доказывает чтение найденных URL |
| [FlagEmbedding](https://github.com/FlagOpen/FlagEmbedding) | Python-библиотека локального retrieval/reranking. BGE-M3 поддерживает dense/sparse/multi-vector; bge-reranker-v2-m3 — multilingual cross-encoder | Переранжирует уже найденные документы, не обнаруживает пропущенные сайты. Нужны веса и ресурсы; выигрыш на русских игровых текстах не измерен. Сначала reranking top-k без смены collector |
| [Crawl4AI](https://github.com/unclecode/crawl4ai) | Локальный Python/Docker crawler, Markdown, CSS/XPath/Regex extraction без LLM; cloud/API — отдельный необязательный продукт | Браузер и лимиты обхода; не отменяет 401/404, cooldown и правила доступа. Тестировать как дополнительный маршрут сложных страниц после существующего collector. Очищенный Markdown не равен доказанному claim |
| [rusBEIR](https://github.com/kaengreg/rusBeIR) | Русскоязычный IR benchmark, NDCG@10/Recall@10; CLI-оценка retrieval-моделей | Это измеритель поиска, не поисковик. Общие датасеты не представляют Hearthstone; нужны также собственные размеченные запросы/источники. Лицензии конкретных данных проверяются отдельно |
| [SAGE](https://github.com/ai-forever/sage) | Русская орфография, модели и оценка исправлений. Уже есть `editor/requirements-sage.txt` и `spell_hints.py` | Не новая зависимость. Текущие подсказки защищены словарями/именами/корпусом и не меняют текст. Не превращать в автопереписывание: проверять ложные исправления и игровые имена на реальных парах |

## Порядок экспериментов

1. Подготовить собственные запросы с известными релевантными источниками и
   фрагментами. Зафиксировать baseline collector/retrieval: охват, Recall@k,
   NDCG@k, задержку, объём обработанных страниц и реальные ошибки доступа.
2. Сравнить дополнительное обнаружение через SearXNG и извлечение через
   Crawl4AI с существующими маршрутами. Сохранять provenance; повторный URL
   и сниппет не считать независимым прочитанным источником.
3. Измерить BGE reranking на том же пуле найденных документов отдельно от
   поиска новых URL. Не приписывать ранжировщику рост покрытия площадок.
4. Качество текста: использовать уже имеющиеся LanguageTool, Hunspell,
   Natasha/Razdel, Vale и SAGE, а человеческие предпочтения собирать через
   [Potato](../editor/docs/evals.md#potato-локальная-слепая-оценка-в-браузере).
   Считать полезность и ложные исправления, сохранение условий/имён/голоса;
   грамматический балл не подтверждает игровые факты или авторскую подачу.

Приоритет для ближайшего измерения: собственный retrieval-набор → BGE
reranker; SearXNG/Crawl4AI добавлять только при доказанном пробеле текущего
маршрута. Существующие trafilatura, optional sentence-transformers,
Promptfoo и SAGE не дублировать ещё одним стеком. Тяжёлые веса сначала
оценивать вне production VPS, где ограничено свободное место.
