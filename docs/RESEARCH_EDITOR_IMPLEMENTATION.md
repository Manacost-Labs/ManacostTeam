## Что получает исследователь и редактор

R1–R6: вопросы читателя и уточнения после прочтения, языковые варианты темы
и сущностей, явный бюджет, содержательный прогресс и проверяемая актуальность.
R7: существующий semantic adapter проверен; он ищет дубликаты, а не ранжирует
ответы на запрос. Без размеченного RU/EN набора и измеренного выигрыша новая
зависимость не добавлялась.

H1–H3: одна расширенная схема handoff v1 проходит compiler, Python native run,
Go decode/encode, writer и factual reviewer. Общий синтетический fixture
`tests/fixtures/editorial-boundary.json` проверяет эту границу. Decision cards
хранят ситуацию, выбор, действие, объяснение, цену, исключение и примеры там,
где есть основания. Неизвестное остаётся gap; ID и hash не доказывают смысл.
Цитаты контрдоказательств проходят ту же проверку полного текста при native
submit. Прямой Go API проверяет форму и связи, но не читает исходные snapshots.

W1–W10: задача читателя и тезис, необязательный выбор начала, обратный план,
объяснения решений, обоснованная авторская позиция без выдуманного опыта,
локальные замечания с пользой и риском, сохранение сильных мест, контекстные
правила и диагностические счётчики. Native review v2 требует strengths,
paragraph_functions, reader_check и whole_article_checked. Старые сохранённые
runs v1 продолжают работать. Фактолог и литературный reviewer получают
материал независимо, без чужого вердикта.

## Проверки

- Полный EditorTeam Python: 748 passed, 36 skipped. Пропуски относятся к
  существующим внешним интеграциям; они не считаются подтверждёнными.
- Полный ResearchTeam: 268 tests, OK. После последней правки compiler его
  15 тестов повторены отдельно, включая общий fixture и журнал противоречий.
- После финальных исправлений публикации и corrections повторены профильные
  Python regression suites: 99/99.
- Go: `go test ./...`, `go vet ./...`, `go build ./...` прошли после исправлений.
  Использован локальный официальный Go 1.26.4 с проверенным SHA256.
- Node eval: 29/29. Ruff для src/tests/sidecars и изменённого compiler прошёл.
- Общие контракты и распакованные portable runtime: 63 теста, OK, один
  существующий skip. Все девять пакетов проверены сборщиком; неизменённые
  архивы сохраняют байты. Повторная сборка `--check` проверяет состав и SHA256.
- `editor-team config validate` и существующий corpus selftest прошли:
  затвор не отклонил ни один из 49 проверенных опубликованных гайдов.
- Существенные регрессии сначала воспроизводились падающими тестами.
  Независимый обзор нашёл дополнительные ошибки обработки failed/blocked,
  будущих дат, LIKELY_CURRENT, локализации entity, punctuation-only правок,
  потери контекста и разных правил в reconstruct. Они исправлены и проверены.
  Повторный независимый обзор: 15/15 адресных тестов, открытых замечаний нет.

Модельные вызовы в unit/integration tests используют фиксированные ответы.
Это доказательство маршрутизации и gates, не живой проверки качества модели.

## Сравнительный пилот и оставшиеся ограничения

[Пилот и команды запуска](RESEARCH_EDITOR_PILOT.md) фиксируют старый commit,
10 новых синтетических development-кейсов, одинаковые входы и бюджеты.
Контрольный прогон: 10/10 неизменённых текстов прошли, 10/10 искусственных
числовых повреждений отклонены. Все 20 переставленных A/B форм остаются pending;
человеческих оценок нет.

Для живого сравнения нужны 8–12 новых реальных материалов с проверенными
эталонами, отдельный holdout, baseline/candidate gateways и человеческие
оценки пользы, голоса и времени. Конфигурации research/editorial/full_process
и формы готовы. Измеренное улучшение естественности, глубины, стоимости или
времени редактора не заявляется. Текущий игровой патч и свежесть встроенного
реестра в этой разработке не подтверждались.

Подготовлены новые переносимые пакеты с отдельными версиями; прежние архивы
сохранены. Публикация GitHub release, развёртывание и публикация статей
не выполняются в рамках этого задания.
