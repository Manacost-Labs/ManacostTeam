# Повторная проверка проекта: 14 октября 2026

Проверена основная копия на macOS, начиная с чистого коммита `9583392`.
Все доступные локальные тесты прошли после перечисленных ниже исправлений.
Это проверка кода, контрактов и упаковки; она не доказывает достоверность
материалов, которые в будущем сгенерирует конкретная модель.

## Найдено и исправлено

1. **Editor CI падал на lint.** В `editor/tests/unit/test_task_context.py`
   отсутствовал разделитель групп импортов. Ошибка I001 подтверждена локально
   и в журнале GitHub; исправлена одной строкой.
2. **CLI зависел от кодировки консоли.** Resolver печатал кириллицу в системной
   кодировке Windows; установщик также падал при пути назначения с кириллицей.
   Оба CLI теперь выводят UTF-8. Новые тесты сначала воспроизвели
   UnicodeEncodeError при принудительной ASCII-консоли, затем прошли.
3. **Некоторые тесты распакованных навыков декодировали UTF-8 как cp1252.**
   Для соответствующих subprocess явно задана UTF-8. Проблема подтверждена
   в Windows CI; ошибочные ответы раньше превращались в `None` после падения
   потока чтения subprocess.
4. **ZIP WordPress не был одинаковым на разных ОС.** Поле `create_system`
   зависело от платформы. Теперь закреплено Unix-значение 3 вместе с уже
   фиксированными датой и правами. Тест с имитацией Windows сначала падал,
   затем подтвердил побайтовое совпадение с опубликованным ZIP 1.0.0.
5. **При отказе API соединение иногда сбрасывалось вместо HTTP 503/413.**
   Повторный Windows CI обнаружил сброс при перегрузке; локальный прогон также
   воспроизвёл сброс во время отправки слишком большого тела. Перед закрытием
   сервер завершает отправку и дочитывает остаток запроса с лимитами 100 мс
   и 576 KiB. Проверены GET/POST при перегрузке, большой запрос, ограничение
   объёма, короткие TCP-фрагменты и закрытие при таймауте.

Новые навыки опубликованы в `release/team-skills/1.7.1`:
EditorTeam 1.7.1, TranslateTeam 1.2.1. Остальные навыки сохранили версии.
Существующие выпуски, WordPress-плагин, игровые ассеты и корпуса не изменены.

## GitHub CI и пределы проверки

Для исходного `9583392` Research CI прошёл. В Editor CI успешно завершились
Go service, Corpus regression, NLP sidecar, deterministic eval contract и
Docker toolchain/E2E. Python matrix упала на исправленной I001.
Portable Team skills упал на перечисленных Windows-проблемах.
Эти результаты относятся к исходному коммиту; исправления повторно
проверены следующими запусками.

В повторном запуске для `e311088` Windows больше не сообщает ошибок CLI,
декодирования или ZIP. Проверки пакетов и XML source kit прошли на Ubuntu,
XML source kit также прошёл на Windows. Windows package job обнаружил
описанную выше отдельную проблему TCP-завершения. В
[итоговом запуске для `3a8ef4c`](https://github.com/Manacost-Labs/ManacostTeam/actions/runs/38542892305)
все четыре jobs прошли: 60 тестов и проверка воспроизводимости на Windows и
Ubuntu, установка/сборка XML source kit на обеих платформах.
[Editor CI для `e311088`](https://github.com/Manacost-Labs/ManacostTeam/actions/runs/38541931911)
прошёл все девять Python jobs (Windows/Linux/macOS × 3.11/3.12/3.13), Go,
NLP sidecar и deterministic eval contract. Повторный Docker job на момент
завершения отчёта ещё выполняется; ранее Docker/E2E уже прошёл на `9583392`.

- Docker daemon и Compose локально недоступны. Docker/E2E подтверждены
  [запуском GitHub для 9583392](https://github.com/Manacost-Labs/ManacostTeam/actions/runs/38539874255).
- 36 пропущенных тестов EditorTeam требуют бинарник Vale; это не успешные
  проверки. Полный Docker E2E не заменяет запуск каждой Vale integration case.
- Реальный WordPress с установленным плагином и ответы платной модели
  не проверялись. Не проверялась актуальность живых игровых источников.
- SVG-валидатор предупреждает о мелких подписях. resvg не поддерживает
  встроенный `@font-face` и использует доступные системные шрифты;
  визуальная проверка не гарантирует одинаковый шрифт во всех браузерах.
- `search_coverage` для старых учебных `provenance-demo` и `BENCH-004`
  сообщает незакрытые семейства поиска, отсутствие challenge search и
  другие пробелы происхождения. Это информационная диагностика с нулевым
  exit code, а не подтверждение готовности исследования. Release benchmark
  проверяет собственные ожидаемые случаи; его PASS нельзя переносить на
  публикационную готовность этих bundles. Учебные данные не переписывались.
- Проверенные словари LoL, Deadlock, Overwatch и Heroes of the Storm остаются
  отдельным этапом; выбор игры и изоляция контекста проверены, полнота
  терминологии новых игр не заявляется.
