# Team standard 1.0.0 — 2026-10-03

- Один основной монорепозиторий, семь независимых модулей и общий реестр контрактов Teams.
- Восемь переносимых навыков: семь Team entrypoints и отдельный `card-shortcodes`.
- Версионированные ZIP/skill, combined plugin для поддерживающих его клиентов, SHA-256, manifests, воспроизводимая сборка и проверка относительных ссылок.
- Подсветка подтверждённых карт с учётом режима, коротких/склоняемых имён и контекста. Скрипт оборачивает только выбранные упоминания и сохраняет исходный текст.
- ResearchTeam: более широкая матрица EN/RU запросов X, Reddit, YouTube, официальных/статистических/специализированных веб-источников; аудит связанных поисков и прочитанных источников по разделам и языкам.
- MarketingTeam включён в монорепозиторий; исходные специализации и лицензии сохранены. JobTeam получил редактируемые исходники прежних `.skill`.
- Перенесены проверенные локальные улучшения EditorTeam: словарь Полей сражений, анализ типов отрицаний и плотности стилистических маркеров. Список происхождения — `editor-source-integration.json`.
- Проверены ранее подготовленные исправления Windows: CRLF snapshots/XML hashes, Node package smoke, редакторские eval guards. SVG работает без обязательного macOS-конвертера; примеры используют относительные пути.
- Правило завершения задачи: проверки, просмотр diff, commit и push без повторного подтверждения владельца.

Личные материалы, секреты и исходные независимые рабочие копии сохранены. Локальные SVG-шрифты и прежние генерированные визуалы не включались без проверки их отдельного изменения. Импорт в облачные аккаунты не выполнялся; доступность custom skills и синтаксис вызова определяются клиентом.
