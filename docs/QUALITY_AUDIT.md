# Проверка исходных фактов и качества текста

Проверка фактов исходника, сохранение смысла при правке и литературное качество
дают три отдельных результата. Хорошо сохранённый исходник может содержать
ошибку; красивый текст может содержать неподтверждённый вывод.

## Работа с корпусом

Новый stdlib-инструмент использует существующий frozen corpus из
`editorteam.publication_benchmark`: manifest, неизменяемые source.md, SHA-256
и train/holdout. Переподготавливать выборку для каждого улучшения нельзя.

```powershell
# Из корня репозитория; после установки EditorTeam.
python -m editorteam.quality_audit prepare build/editorial-lab/benchmark-preview --output build/quality-audit/tasks
python -m editorteam.quality_audit summarize build/editorial-lab/benchmark-preview --reviews build/quality-audit/reviews.json --evidence-root build/quality-audit --output build/quality-audit/report.json --markdown build/quality-audit/report.md
```

В распакованных editor-team и manacost-publish задайте `PYTHONPATH=python`.
Инструмент не вызывает платную модель и не создаёт отзывов автоматически.
Независимый reviewer читает полные исходники и сохраняет отдельный JSON-отзыв.
Исходники, отзывы, snapshots, слепые ключи и оценки остаются приватными,
в игнорируемой папке; в релиз входят код и синтетические тесты.

Отзыв содержит `case_id`, `source_sha256`, `reviewer_kind=model`, имя reviewer,
`reviewed_at` с часовым поясом, `temporal_scope=historical|current`,
`target_period`, `claim_scope=sampled|complete`, `literary`, `source_facts`
и явные `limitations`. Пример формата — синтетические fixtures
`editor/tests/test_quality_audit.py` в checkout; в portable-пакете их нет.

## Проверка исходных утверждений

Каждый sampled claim имеет уникальный `claim_id`, дословный `quote` исходника,
`kind`, `status=supported|contradicted|unverified|outdated`, объяснение,
`search_queries` и `evidence`. Цены, механики, мета и рекомендации требуют
подходящих периода, игры, режима и области сравнения. Современная механика
не подтверждает исторический винрейт. Отсутствие доказательств — `unverified`,
а не автоматически найденная ошибка.

Для supported/contradicted/outdated нужна независимая опора: URL,
короткая дословная цитата, локальный UTF-8 snapshot и его SHA-256,
authority (official/statistics/expert), явные `scope_matches`/`time_matches`
и время получения. Механики требуют official, числа — official/statistics.
Статья не может подтвердить себя тем же URL. Изменение snapshot, выдуманная
цитата, неизвестный case и повторный отзыв блокируют отчёт.

`capture_path` указывает на отдельную квитанцию получения: `source_url`,
`retrieved_at`, `snapshot_sha256`, `method=web.open|web.find|mcp`,
реальный `tool_reference`, `content_scope=excerpt|full`.
URL, время и хеш обязаны совпадать с evidence. Это проверка происхождения
и целостности записи; она не доказывает правдивость сайта, полноту извлечения
или правильность смыслового вывода reviewer.
Квитанция и tool_reference записываются проверяющим: валидатор сверяет поля,
но самостоятельно не аутентифицирует вызов инструмента и не проверяет, что
указанный reference существует. Это заявленные reviewer метаданные получения.

Проверяйте не только числа: «ниже» и «выше», строгий и нестрогий порог,
«лучший в архетипе» и «лучший в классе», отрицание, приписанную причину
и силу прогноза. Неподтверждённые claims попадают в `search_queue` с периодом
и опробованными запросами. Наличие очереди не означает проведённый поиск;
`attempted_unresolved` отражает заявление reviewer о запросах.

`current_facts_verified` остаётся false для всех модельных отзывов.
`model_current_support` отдельно отражает модельное утверждение о полном
современном охвате; сам инструмент не способен подтвердить полноту.
Human gold и разрешение на публикацию оформляются отдельно прежним процессом.

## Проза и сохранение при правке

В `literary.dimensions` обязательны usefulness, coherence, natural_russian
и author_voice со статусом pass/needs_work. `strengths` сохраняет удачные
фрагменты, которые не следует переписывать. `findings` содержит точную цитату,
категорию, severity, причину и адресное предложение. Сленг и обращения
к читателю не считаются ошибкой сами по себе. Проблемы отсутствующих картинок,
ссылок и навигации отделяются от качества авторской прозы.

Необязательный `edit_review` связывает candidate с SHA-256, результатом
проверки всех изменений, списком неподтверждённых добавлений и дословными
attestations каждого sampled claim. Успешный результат называется
`passed_model_review`; он не меняет достоверность исходных фактов.
Без candidate сохранение при правке имеет статус `not_run`.

В рабочем редакторском postflight добавлены консервативные lexical guards:
при совпадающем остальном предложении смена направления/строгости числового
порога и области превосходства архетип→класс отклоняется. Перестановка
предложений и равнозначные «ниже/менее» допускаются. Произвольный парафраз,
межъязыковой перевод и сложные области сравнения требуют смыслового review.

Для измерения улучшения используйте уже существующие blind_cases и
publication_benchmark.paired_summary: одинаковые источники, периоды, бюджеты
и отдельный ключ вариантов. Не настраивайте промпты по holdout.
Без реальных парных оценок качество и экономия времени остаются null.

## Ночные проверки

Без ключа workflow сохраняет `status.json` с `run_status=not_run`, причиной
`no_provider_key`, null для share и false для model_evaluation_completed.
Причина видна в GitHub Summary; artifact сохраняется и при пропуске.
Это не успешная оценка качества модели.

Пустой/неполный прогон `run_evals.py` возвращает exit 2 и failed/partial.
Знаменатель доли успеха включает все запрошенные кейсы и не уменьшается
из-за исчезновения каталога: список кейсов закреплён отдельно
в `editor/tests/evals/inventory.json`; расхождение состава останавливает запуск.
Отказ шлюза не засчитывается как удачная правка только потому, что вернулся хороший
исходник. В Markdown отсутствующий кандидат явно помечен NOT RUN.
Детерминированная оценка и завершённый модельный вызов сохраняют
`quality_validated=false`: человеческое предпочтение и точность источников
они не измеряют.
