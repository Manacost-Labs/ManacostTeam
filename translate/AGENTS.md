# TranslateTeam

Этот модуль готовит игровые материалы для перевода Codex, но не вызывает модель и не хранит переведённые материалы в Git.

- Данные из игровых клиентов, утверждённые глоссарии и translation memory хранятся в `data/` и игнорируются Git.
- Не выгружайте внешние страницы, cookies, API-ключи или корпуса в репозиторий.
- Сохраняйте ссылки, числа, Markdown и подтверждённые термины; спорный термин направляйте в review, а не утверждайте автоматически.
- Перед изменением поведения запускайте `python -m unittest discover -s tests -v`.
- Docker-проверка нужна, только если Docker доступен; не объявляйте её пройденной без реального запуска.
