## [1.20.0] — 2026-10-27

- EditorTeam 1.15.0: critic получает до двух повторов после ответа не по схеме (`EDITOR_CRITIC_RETRIES`), каждый с последним ответом и полным списком ошибок. Правка запятой, тире или кавычек внутри сильного фрагмента не считается его потерей.
- Отклонённая правка по-прежнему возвращает исходник; однозначная корректура из кандидата приходит отдельно в `proofread_salvage`. Без находки Hunspell или LanguageTool в этом месте переносятся только ё и улучшения типографики; публикационного допуска это не даёт.
- Совет с условием проверяется во всех предложениях с его картой (`condition_repeats`). Ответ, обрезанный по лимиту токенов, — ошибка; сроки анализаторов растут с длиной текста; LanguageTool передаёт точный отмеченный фрагмент. Вход critic короче: diff выравнивается по строкам, однотипные предупреждения сводятся.
- В golden-эталоны `audit` добавлены диагностические поля 1.18.0. Живой прогон с моделью и `blind_review.js gate` после изменений не выполнялись; улучшение текста не заявляется. Подробности: docs/EDITOR_WEAKNESS_FIXES_2026-10-27.md.

## [1.19.0] — 2026-10-25

- EditorTeam 1.14.0: пары «черновик → эталон» владельца, слепое A/B-сравнение с рубрикой «интересно / механично» и протокол «поправка → кейс»; детектор пересказа текста карт, голых упоминаний и плотности инсайта с порогами по корпусу. Метрика качества появится только после реальных пар владельца.
- ResearchTeam 1.11.0: recall-бенчмарк на 37 кейсов с разбивкой по классам источников и историей, поиск волнами (en/ru/zh, переход по ссылкам, опровержения) с критерием насыщения, обязательная карта покрытия; тип записи insight и блок «Неочевидное» в editor-ready с проверкой валидатором. Очередь расшифровок хранит команду списком аргументов.
- Manacost Publish 1.12.0 получает обновлённые общие контракты editor и research.
- Release-архивы навыков больше не коммитятся: сборка пишет их в игнорируемый `build/team-skills/<версия>/`, в Git остаётся манифест (`index.json` с `download_base`, `SHA256SUMS`), архивы публикуются ассетами GitHub Release через `tools/publish_team_skills.py` с проверкой SHA256. Установщик берёт локальную сборку, `--archives DIR` или ассет релиза и понятно останавливается, если ассет недоступен.
- Архивы 27 прежних выпусков (1.0.0–1.18.0, 499 файлов) перенесены в GitHub Releases `v<версия>` со сверкой SHA256 и удалены из рабочего дерева; история Git не переписывалась.

## [1.18.0] — 2026-10-23

- EditorTeam 1.13.0: общий Go-контракт 26 практик, 5 проверок логики и 7 сохранения во всех редакторских маршрутах, включая unchanged; отдельная проверка исходных ошибок и доказательное исправление по полным источникам.
- Снимки источников привязаны к точным SHA256, reviewer сообщает snapshot-доступ. Проверка предоставленных материалов не объявляется проверкой всех внешних фактов. Отрицательная оценка голоса и нерешённые смысловые замечания несовместимы с accept.
- Изменения голоса и сильных фрагментов требуют точных пар цитат с пользой и риском. Частотные рекомендации словаря не являются механическими запретами лексики. Инструментальные audit/analyze/validate-edit явно отделены от публикационного допуска.
- Manacost Publish 1.11.0: повторная проверка действующего контракта при export; сохранённые v1/v2 receipts не обходят текущие требования. История остаётся читаемой, новый допуск требует текущего run и независимых reviews.
- ResearchTeam 1.10.4 получает обновлённые общие редакционные контракты. Прежние release-архивы сохранены. Тесты валидаторов не являются доказательством улучшения каждой статьи.

## [1.8.0] — 2026-10-15

- EditorTeam 1.8.0 и Manacost Publish 1.2.0: независимый аудит исходных фактов и прозы по frozen corpus. Хеши исходников, точные цитаты, внешние snapshots и capture receipts проверяются; модельный отзыв не подтверждает human gold или текущую истинность статьи. Неподтверждённые тезисы образуют адресную очередь поиска.
- Проверены 12 полных приватных материалов: 38 выбранных утверждений (12 supported, 3 contradicted, 23 unverified) и 43 литературных замечания, включая проблемы извлечения. Исходники, pending-аннотации и holdout сохранены; процент улучшения не заявляется.
- Редакторский postflight замечает смену направления/строгости порога при тех же числах и расширение превосходства с архетипа на класс в совпадающей формулировке. Инструкция независимого reviewer дополнена проверкой области сравнения, причинности и модальности.
- Ночные проверки сохраняют явный NOT RUN без ключа. Неполные/пустые прогоны завершаются с ошибкой; пропавшие кейсы остаются в знаменателе, хороший исходник при отказе шлюза не считается удачной правкой. [Контракт и ограничения](docs/QUALITY_AUDIT.md).

## [1.7.2] — 2026-10-15

- Оформлен выпуск ManacostTeam на GitHub: девять переносимых навыков, combined plugin, контрольные суммы и WordPress-плагин 1.0.0. Страница загрузок обновлена с 1.0.1 на актуальные версии; ранее собранные архивы сохранены без изменений.
- EditorTeam применяет проверку фактов с учётом исходника во всех редакторских маршрутах; ResearchTeam и Manacost Publish передают проверяемые источники и отзывы. Подробности, совместимость и границы проверки — [заметка о выпуске](docs/releases/1.7.2.md).
- Установщик явно читает метаданные и Compose в UTF-8: установка навыков работает в Windows с системной кодировкой cp1251. Регрессионный тест проверяет установку при отключённом UTF-8 mode; проверка симлинков отдельно сообщает об отсутствии прав на их создание.
